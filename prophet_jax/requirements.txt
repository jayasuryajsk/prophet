# prophet_jax — JAX/Flax port of the prophet chess engine.
#
# IMPORT ORDER: prophet_jax/__init__.py imports jax BEFORE any submodule (hence
# before numpy). On Homebrew Python, numpy and jax/torch each bundle their own
# OpenMP/BLAS (libomp) and only a jax-first (or torch-first) init is stable.
# Keep `import prophet_jax` (or `import jax`) as the first heavy import.
#
# ---------------------------------------------------------------------------
# Pick ONE jax line for your hardware, then install the rest:
#   GPU (CUDA 12):   pip install -r requirements.txt
#   CPU-only / Mac:  comment out the jax[cuda12] line below, uncomment plain jax,
#                    then `pip install -r requirements.txt`. The smoke test
#                    (smoke_test.py) runs fully on CPU — no GPU needed.
# ---------------------------------------------------------------------------
